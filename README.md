# Currency Converter 💱

A simple and responsive currency converter web application that allows users to convert amounts between different currencies using exchange-rate data.

## 🚀 Live Demo

**[View Currency Converter](https://currency-converter-2sepdfodl-suryanshsharma31s-projects.vercel.app/)**

## 📌 Features

* Convert currencies between multiple countries
* Fetch exchange-rate data using an external currency API
* Dynamic currency selection
* Real-time conversion based on available exchange-rate data
* Responsive user interface
* Simple and clean design

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* REST API
* Fetch API

## ⚙️ How It Works

1. Enter the amount you want to convert.
2. Select the source currency.
3. Select the target currency.
4. JavaScript fetches the exchange-rate data from the API.
5. The application calculates and displays the converted amount.

## 🔌 API Integration

The application uses an external currency exchange-rate API to retrieve currency conversion rates.

## 💻 Run Locally

Clone the repository:

```bash
git clone https://github.com/SuryanshSharma31/currency-converter.git
```

Open the project folder:

```bash
cd currency-converter
```

You can then open `index.html` in your browser or use the Live Server extension in VS Code.
